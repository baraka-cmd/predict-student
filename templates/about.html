À propos de Predict'Student

Découvrez l'histoire, la mission et la technologie derrière notre plateforme de prédiction académique.

Notre Mission

Predict'Student est une plateforme innovante conçue pour aider les établissements d'enseignement, les conseillers pédagogiques et les étudiants à anticiper les performances académiques.

Grâce à l'intelligence artificielle et au Machine Learning, notre outil analyse 14 critères clés pour prédire avec précision la note finale d'un étudiant et identifier les risques d'échec avant qu'il ne soit trop tard.

Prédictions fiables à 98%
Analyse de 14 critères
3 modèles comparés
1000 étudiants analysés

Intelligence Artificielle

Modèles entraînés sur des données réelles d'étudiants pour des prédictions précises.

Fiable & Sécurisé

Aucune donnée stockée. Les prédictions sont calculées en temps réel.

Comment ça fonctionne ?

01

Saisie des données

Remplissez le formulaire avec les 14 caractéristiques de l'étudiant : âge, heures d'étude, absences, notes, etc.

02

Analyse par l'IA

Notre pipeline de Machine Learning traite les données via StandardScaler, OneHotEncoder et 3 modèles de régression.

03

Résultat instantané

Obtenez la note prédite, la mention, une jauge visuelle et des recommandations personnalisées.

Technologies utilisées

Python

Langage de programmation principal pour le traitement des données et l'entraînement des modèles.

Flask

Framework web léger pour l'API backend et le rendu des pages HTML.

Scikit-learn

Bibliothèque Machine Learning pour la Régression Linéaire, Random Forest et Gradient Boosting.

HTML5 / CSS3

Structure et design responsive de l'interface utilisateur.

JavaScript

Interactions dynamiques, animations, appels API et affichage des résultats.

Régression

3 algorithmes comparés : Régression Linéaire, Random Forest Regressor, Gradient Boosting Regressor.
